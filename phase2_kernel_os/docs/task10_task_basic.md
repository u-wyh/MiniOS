# Task10-1：任务系统雏形

## 1. 什么是任务（Task）

任务可以理解为“操作系统要运行的一段独立执行流”。当前阶段还不是完整进程系统，只是最小的任务切换雏形。

## 2. 什么是上下文切换

上下文切换就是：先保存当前任务的执行现场，再恢复另一个任务的执行现场，让 CPU 继续执行另一个任务。

## 3. 为什么要保存 esp

当前最小实现里，每个任务最关键的现场就是它自己的栈位置。只要保存好 `esp`，就能回到这个任务上次停下来的地方。

## 4. 栈在任务切换中的作用

栈里保存了函数返回地址、寄存器现场以及任务运行状态。任务切换的本质，就是把 CPU 从“当前栈”切到“另一个任务的栈”。

## 5. 执行流程

shell -> switch_task -> context_switch -> 新任务执行

当前实现里，任务 A/B 每次只输出一个字符，然后主动让回 Shell，因此可以通过多次输入 `task` 手动观察 A/B 交替。

## 6. 常见错误

- 栈初始化错误 -> 崩溃
- esp 保存错误 -> 跳飞
- 没有正确 ret -> 死机

## 7. 一句话总结

任务切换的本质是“切换栈”。
